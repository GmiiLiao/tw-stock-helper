# tw-daily-heatmap｜台股每日熱力分析（股市分析師作業手冊）

> **狀態**：v1，2026-10-04 建立。由三位分析師草案合併（權值股指數貢獻／個股族群熱力／次日使用與紅隊），數字皆用 `second-brain/official` 真實鏡像實測；程式已用 2026-10-02 驗證（指數殘差 +1.28 點＝0.27bp，綠）。
> **用途**：描述資料日收盤事實，**非投資建議**，比對一律未扣成本。

## 0. 先讀這六條
1. **不預測、不計分。** 輸出刻意沒有 `score/signal/buy/rank` 欄位，`useRules.usedForScoring=false`。**不得**進模型分數、排序、濾網、AI 波段／新聞識讀 LLM。要進，須先過兩窗＋OOT、影子 ≥20 交易日、使用者核可。
2. **報酬用官方參考價**（上市 TWT84U 第 3 欄；上櫃 `收盤−漲跌`，除權息日用前日「次日參考價」）。MI_INDEX 除權息日符號 `X`、漲跌價差 0.00 **不是平盤**；`chipArchive.closeJson` 沒有前收，不可用來算日報酬。
3. **指數貢獻用前一日實際收盤為基期**（價格指數不調整現金股利）；只有 |參考價/前收−1|>10%（分割、減資）才改用參考價。除息機械影響另列 `exDivMechanicalPts`，不可誤讀為賣壓。
4. **官方沒有逐檔權重**，自算：權重＝收盤×發行股數（上市 t187ap03_L 為主、MI_QFIIS 備援；MI_QFIIS 會過期，緯穎 2026-09-02 分割後 21 日未更新）。不新增網域。
5. **核心只讀官方產業別 `industry`**。chains／segments／groups 標「站內整理／推導」、產品族標「AI待驗」，只顯示於 `layers`，n 小用 z、`lowN` 標「僅觀察」，不可解讀為「其餘無關」。
6. 缺值寫「來源未提供」不補 0；非交易日不產生檔；定版寫一次、不被重跑覆蓋。

## 1. 用法
```bash
node scripts/daily-heatmap.mjs                       # 最後交易日；閘門全過才寫 second-brain/daily-heatmap/{日}.json.gz
node scripts/daily-heatmap.mjs --date 2026-10-02 --dry-run --md   # 不寫檔，印 Markdown
node scripts/daily-heatmap.mjs --force               # 開盤前修補：舊檔留 .r1；開盤後只寫 .amend-N
```
對上游 0 請求，只讀 `second-brain/official`、`wiki/_graph/stocks.json`、`backup/chipArchive`（法人，選用）。
程式：`scripts/daily-heatmap.mjs`、`scripts/lib/daily-heatmap/{inputs,stats,index-contrib,compute,gates,render}.mjs`。

## 2. 輸入欄位位置（皆 gz JSON `{meta,payload}`；表用 title 定位，不用索引）
| 資料 | 路徑 | 欄位 |
|---|---|---|
| 上市收盤、官方加權指數、家數 | `www.twse.com.tw/twse_mi_index/{日}` | 個股表 title 含「每日收盤行情」：收盤[8]；「價格指數(臺灣證券交易所)」列「發行量加權股價指數」（漲跌百分比偶為 `--`，用點數反推）；「漲跌證券數合計」用「股票」欄 |
| 上市參考價 | `twse_twt84u` | 漲停[2]、**參考價[3]**、跌停[4]、前日收盤[6]（欄名重複，只能按位置） |
| 上市股數 | `openapi.twse.com.tw/twse_oa_opendata_t187ap03_L`（無歷史，檔名日≠內容日）；備援 `twse_mi_qfiis` [3] | 兩來源差 >1% 列 `sharesDisagree` |
| 上櫃 | `www.tpex.org.tw/tpex_dailyquotes` tables[0] | 收盤[2]、漲跌[3]（可為「除息」）、發行股數[15]、次日參考價[16]/漲停[17]/跌停[18] |
| 交易日 | `twse_mi_index/_manifest.json` status=ok | 「前一交易日」只取清單，不用日曆減一 |

## 3. 輸出（確定性：鍵序固定、取整固定、payload 不含時間戳）
`market`、`universe`（排除清單）、`industries[]`（官方，含 `heat`/`heatPct`）、`index`（貢獻、前 20 權重、前 N 大拆解、拉抬／拖累、`nextBasis` 隔日權重、殘差等級）、`breadth`、`sharesDisagree`、`layers`、`board`、`watch`、`stocks`（緊湊陣列）。單日 gz 預估 25–40 KB。
- **熱度** `heat = 0.5·Z(超額等權)＋0.5·Z(漲停占比)`，僅 n≥8 的產業橫斷面標準化（n≥5 才顯示）。實測 1,023 日隔日群超額 IC 約 0.08–0.095（樣本外 501 日仍成立），但**約 40% 來自今日漲停連板（買不到）**，且是等權毛額籃子；個股層沒有動能（IC −0.026）。
- **族群報酬用等權＋中位數**；成交值加權有同期偏誤（近 60 日 +0.58%/日 vs 等權 +0.02%），只當診斷 `valW`；市值權只做指數貢獻。
- **權值股「前 N 大」依前一日權重排序**（才能解釋當日貢獻），收盤後權重另列為隔日基準；|指數漲跌|<0.3% 不輸出「占指數漲跌」比例。
- **殘差分級**（÷前日指數）：綠 ≤1bp／黃 ≤3bp／紅 >3bp（紅＝歸因不可靠，不下結論）。1,022 日實測：中位 0.3–0.5 點，p99 約 5bp，最大 28.8bp。
- **共振標籤**：A 族群共振／B 產業共振／C 個股獨行／D 無緊密群連結（D 只能說「wiki 無連結」）。

## 4. 閘門（看資料不看時鐘；硬閘門不過＝不寫檔，寫 `_pending/{日}.json`）
四份硬輸入（MI_INDEX、TWT84U、MI_QFIIS、TPEx）manifest 皆 `final` 且 `echo==資料日`，且**表內民國日期自行再驗**；上市≥max(900, 0.97×前20日中位數)、上櫃≥max(700, 同)；參考價缺 ≤0.5%；成交值對帳 Σ4 碼 ÷ 官方一般股票 ∈[0.99,1.02]；指數殘差硬失敗 >50bp、軟警告 >5bp。已定版不覆蓋；非交易日不產檔；過下一交易日 08:30 仍未定版寫 `_alerts/LATEST.json`，盤前簡報須顯示「昨日熱力未產出」。

## 5. 隔日使用規範
| 消費端 | 可以 | 不可以 |
|---|---|---|
| 盤前簡報 | 以「昨日收盤事實」引用 | 預測語氣（續強／看好）；LLM 只准吃事實欄位 |
| 隔日沖／波段／做空風控 | 離線研究當診斷欄（寫入命中／漏網記錄） | 進分數、排序、濾網、取代 sectorWind 尾 3 |
| 新聞識讀 | — | 任何方向（循環論證） |
常見誤讀：權值股貢獻占比高≠多空（實測隔日無顯著、近 60 日符號反轉）；除息日指數下跌≠賣壓；熱度前三≠明天買；「指數漲但漲家數<跌家數」近一年占漲日 34%，不單獨當警訊。

- 當晚消息排行（`GET /api/twse/after-market-news`、純函式 `scripts/lib/after-market-news.mjs`）：**媒體 M**（`newsVerdict`，AI 讀完內文）依「強度×信心×確定性×新穎×尚未反映」先驗權重排序；**官方 O**（`mopsNews` 收盤後公告）依 §4.1 事件基礎權重排序，類型只靠公告主旨比對（未讀內文），方向只有規則強制類才標；例行公告與未分類只計數。**O、M 分開排、分開算占比、不加總**；輸出叫 weight／share，不叫 score／signal；權重未經量測，頁面明標「顯示排序，非分數」。

## 6A. 對帳與校正（`node scripts/verify-daily-heatmap.mjs --days 60`，2026-10-04 結果）
| 項 | 比對對象 | 結果 |
|---|---|---|
| V1 家數 | 官方「漲跌證券數合計」股票欄 | 官方把**除權息日個股（符號 X）與無前收者歸「無比價」**，本頁以參考價計報酬會把它們算進漲跌 → 對帳用「排除這些檔」口徑：差中位 0、最大 4（門檻 ≤5）；全口徑多出的檔數＝除權息檔數（中位 8、最大 41） |
| V2 指數殘差 | 官方加權漲跌點 | 60 日：綠 57／黃 2／紅 1，|bp| 中位 0.16、最大 3.34；3 個非綠日全是除權息日（07-09、08-04、08-18） |
| V3 成交值 | 官方一般股票成交金額 | 1.0004～1.0075 |
| V4 收盤 | chipArchive.closeJson 逐檔 | 60 日 100% 相符 |
| V5 sectorWind | 同名產業 valW vs avgChg | Spearman 中位 0.930（最小 0.793）、方向一致率中位 0.929 |
| V6 人工抽檢 | 原始檔獨立重算 | 2330（10-02、09-16 除息日）、6488（上櫃）皆相符 |
- **已校正**：歷史重建日 MI_QFIIS 發行股數在分割／減資後仍是舊股數（緯穎 6669 於 2026-09-03～09-17 殘差紅 3.4～4.2bp）。`buildSharesFix`：t187/qfiis 比值 ≥1.5 或 ≤1/1.5，且前 30 個交易日內有參考價/前收跳動 >25% 的事件、價格比與股數比相差 <15% 互相印證，才改用 t187 當前股數；結果輸出 `sharesCorrected`。校正後非綠日由 10 天降為 3 天，|bp| 中位 0.33→0.16。重建檔（`rebuilt`）已用此規則重產；正式定版日（t187 當日檔存在）不需要。
- **除權息拆分（已實作，從 2026-10-05 起生效）**：指數不調整現金股利、配股與現增由指數公司調整除數（市值中性）。貢獻改為 `股數×[(收盤−參考價)×(1+配股率)−現金股利]`，無成交時以參考價為收盤；`exDivMechanicalPts` 只算現金股利的機械下跌，`exDivSplitN` 為已拆分檔數。現金股利／配股率取自鏡像每日快照的 TWT48U_ALL 預告表（`loadExDivPlan`），**每檔先自我驗證**：`(前收−現金)/(1+配股率)` 須對上官方參考價（±1 檔升降單位），對不上（單位或資料有誤）或有現增認購者不採用、維持舊口徑。預告快照鏡像只從 2026-10-02 起有 ⇒ **更早的歷史日無法拆分**，仍是舊口徑（殘差偏負、`exDivFlag` 事先標示，目前 3 個非綠日 07-09／08-04／08-18 即此類）。TWT49U 只有「權值+息值」總額，拆不出現金／配股。
- 對帳也發現與修正：本頁 `breadth` 在有官方家數時直接採官方（上市），`market.up/dn` 則是兩市參考價口徑，兩者本來就不同；對帳腳本的 V1 一度因採用定版檔自己的 breadth 變成自我比對，已改為由原始檔獨立重算。
