## 共識與關鍵發現（實測）
1. **昨日／今日卡＝事後回顧、明日卡＝觀察**。昨日、今日的個股名單是「事後選取」，叫「回顧名單／焦點名單」；只有明日卡叫「資料觀察名單」並進事後對答案。名單不給價格目標、停損、買賣指令。
2. **「明日預期」只能寫條件式觀察點＋歷史條件分布，不是預測**：卡片產生時真正影響明天的外部變數（今晚美股）還沒發生。建議另加 07:30–08:35 早晨補寫輪。
3. 外部→台股連動真實但集中在**開盤跳空**：隔夜費半對加權跳空 ρ≈0.62（半導體個股 0.76，n=468）；對個股開→收無關；費半只解釋加權收盤變異約 35%。文章不得把當天漲跌全歸因美股。日韓龍頭→台灣同族群只有記憶體、被動元件、設備成立（n=39，初步）。
4. 動能指標只有「族群熱度隔日 IC 0.08–0.095（約 40% 來自連板）」有實測；權值貢獻占比、廣度、期貨 P/C 等無顯著，只能描述。
5. 資料缺口：聯準會／央行／BLS／美債／官方匯率（網域未登錄不可用）；台指期夜盤與美股期貨歷史、ADR 歷史、原物料歷史（僅 16 天）；處置／注意歷史名單只有 10-02；熱力歷史 59 檔全是 rebuilt（wiki 前視）；日曆只有 FOMC。
6. 站上資料問題（只報告未修）：`taifexPositions.foreignTxfNetOI` 實為交易口數淨額（−456）而非未平倉淨額（官方 −80,304）；晨報 AI 看跌理由曾與費半方向矛盾；`marketReports.topPicks` 含買進／目標／停損價，desk 不得引用；官方 O 管線誤判（光寶科 88.5 億資本支出被判例行）。
7. **AI 防亂寫機制**：數字一律槽位 `{{id|fmt}}` 由程式填值、AI 不輸出裸數字；證據引用 `[ref:id]`；R01–R25 機械查核（數字授權、池內 5–10 檔、禁用語與預測句型、傳聞、M／O 不加總、AI 待驗標示、風險旗標排除、免責固定欄位、日期與資料日一致）；失敗降級：Claude 主引擎 → Ollama 精簡版 → 現有模板版（標示降級）。
