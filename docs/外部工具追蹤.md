# 外部工具追蹤（External Tool Tracker）

本檔記錄台股助手參考／整合的外部開源專案，以及各專案「可借鏡點」的整合狀態。
**用途**：日後定期 re-check 這些 repo 有無更新，決定是否吸收新做法。

## 如何 re-check（給未來的自己 / Claude）
1. 逐一 `WebFetch` 下方每個 repo 的 URL，問「有哪些新 skills/agents/features？近期 commit？」
2. 與本檔「可借鏡點」表比對，找出「未整合且對台股隔日沖/散戶有價值」的新項目。
3. 有值得做的 → 更新對應 daemon skill / 前端，並回填本表狀態與 `最後檢查` 日期。
4. 台灣在地限制要記得：**無證所稅**（TLH 節稅賣損不適用）、LINE 滲透率高、專注隔日沖短線。
