# 技術評分規範 v3（2026-09-30 使用者核可）

> 取代「五大因子（v2）」的設計方法；v2 在 v3 通過本規範驗證並於影子模式前瞻勝出前**照常服務、不修改**。
> 起因：v2 名為五大因子，實際只有 3 個變數（今日漲跌幅重複計分 5 次）、只看單日、因子名稱與內容不符、
> 以隔日開盤驗證卻被用在持股汰弱留強、分數無機率意義。v2 樣本外相對超額 +0.29pp（CI [−0.00, 0.59]），線上前瞻 5 日 −0.84pp。

## 1. 用途與期限（兩套分數，不混用）

| 分數 | 決策用途 | 驗證標籤（y） |
|---|---|---|
| **短線分數 S** | 盤後選隔日候選 | 隔日跳空：`open[t+1] / close[t] − 1` |
| **波段分數 W** | 持股汰弱留強、投資論點、波段選股 | 5 日：`close[t+5] / open[t+1] − 1`；20 日：`close[t+20] / open[t+1] − 1`（與 AI 波段口徑同） |

- 標籤一律取**超額**：減去當日「可交易宇宙」等權平均（成本對所有標的相同，超額口徑下抵銷）。
- 價格以 priceEvents 係數還原（除權息／減資）。

## 2. 可交易宇宙（入選門檻，不計分）

當日 t 同時滿足：四碼普通股（非 00 開頭 ETF）；收盤 ≥ 10 元；20 日均成交額 ≥ 5,000 萬元；近 60 日資料齊全；
當日**未收在漲停／跌停**（收盤價買不到或賣不掉的不列）；非處置股（處置狀態另以風險標記呈現）。

## 3. 因子定義（只用 t 日收盤〔含〕以前可得資料）

| 因子 | 子因子（預先宣告方向＝數值越大越「多方」） | 資料 |
|---|---|---|
| **M 動能** | `r20`＝20 日報酬、`r60`＝60 日報酬 | 收盤 |
| **T 趨勢** | `maAbove`＝收盤高於 MA5/20/60 的條數、`dMa20`＝收盤距 MA20 %、`brk20`＝收盤 ≥ 前 20 日最高收盤（0/1） | 收盤 |
| **V 量能** | `volX`＝當日量 ÷ 前 20 日均量 | 成交量 |
| **F 籌碼** | `inst5`＝外資＋投信 5 日買賣超合計 ÷ 前 20 日均量 | 法人（chipArchive.instJson） |
| **R 風險** | `vol20`＝20 日日報酬標準差、`dd60`＝距 60 日最高收盤跌幅（≤0）、`rsi5` | 收盤 |

- 子因子 → 因子：子因子各自做**當日橫斷面百分位**（0–100），因子＝子因子百分位平均（方向依上表，不做資料探勘翻轉）。
- **R 的方向＝「風險越低分數越高」**：子因子取 `−vol20`、`dd60`（越接近 0 越好）、`−rsi5`（過熱為風險）。
- 缺資料（例：法人缺 ≥3 日）時該子因子以中性 50 計，並在報告列出缺值比例。
- 任兩因子當日百分位的平均相關 |ρ| 必須 < 0.5（正交性）；不符者合併或剔除，並記入驗證報告。

## 4. 計分

1. 每日每因子百分位 P_f（0–100）。
2. 權重 w_f＝**訓練期**因子的平均日 IC（Spearman，因子百分位 vs 超額標籤）；IC 為負且符合 §5 一致性者允許負權（報告需標「反向」）；未通過 §5 者 w_f＝0。
3. 總分＝Σ w_f·P_f ÷ Σ|w_f|，再做當日橫斷面百分位 → **輸出 0–100 百分位與十分位**（D1 最弱 … D10 最強）。
4. 權重定案後寫入 `scripts/data/scoring-v3-weights.json`（含版本、資料雜湊、訓練區間），盤中／日常計算只讀此檔，不在線上重估。

## 5. 驗證門檻（全部通過才可進影子模式）

- 資料：訓練 ≥ 480 個交易日、樣本外 ≥ 120 個交易日，**日期不重疊**、切點固定寫入報告。
- 重疊標籤的 t 值以**非重疊抽樣**計（5 日標籤每 5 日取 1、20 日每 20 日取 1）。
- 每個因子：訓練與樣本外的平均 IC **同號**，且合併 |t| ≥ 2；否則權重 0。
- 總分：
  1. 訓練與樣本外平均 IC 皆 > 0 且 t ≥ 2；
  2. **D10 − D1 超額價差**兩段皆 > 0；
  3. 市況分層（當日大盤等權平均報酬 > 0 為多方日、否則空方日）兩層 IC 同號；
  4. **安慰劑**：打亂日內標籤 20 次，平均 IC 的絕對值 < 真實 IC 的 1/3。
- 報告必列：各因子 IC／t（兩段）、因子相關矩陣、十分位超額表、市況分層、安慰劑、樣本數。

## 6. 治理

- 版本號 `scoring-v3.x`、資料雜湊、訓練區間、複審日（≤ 90 日），登記於 daemon `WEIGHTS_REGISTRY`。
- 監控：每日滾動 60 日 IC；連續 20 個交易日 < 0 ⇒ 開發者通知＋觸發重訓；每季至少重訓一次（重訓同樣須過 §5）。

## 7. 呈現

- 顯示「全市場前 x%」與十分位；不再使用未校準的 60／50 門檻。
- 處置／注意股：風險標記＋排除於宇宙，不做固定扣分；若要扣分，幅度須以 §5 方法量測。

## 8. 影子模式與切換

- v3 通過 §5 後，daemon 每日盤後計算 v3（S、W）並寫 `scoringV3/latest`、`scoringV3/{資料日}`，與 v2 當日 Top20 並存。
- 記分板以同一標籤口徑比較 v3 Top20 與 v2 Top20 的前瞻超額；**累積 ≥ 20 個交易日且 v3 較佳（差值 CI 下界 > 0 或兩者皆負時 v3 損失較小）** 才提請使用者切換。
- 切換前 v2 不動；切換後 v2 保留為對照。
